# StudioSet desktop — releases

Installers and update files for the StudioSet desktop app. This repository holds no source code: builds are published
here automatically and the app checks the latest release for updates.

**Download:** [latest release](https://github.com/NGDF-UY/studioset-releases/releases/latest)

- macOS (Apple silicon and Intel): `StudioSet-<version>-mac-<arch>.dmg`

Help: support@studioset.app
